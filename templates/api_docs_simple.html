🔧 系统端点

GET /api/health

健康检查，返回所有服务的状态
curl http://127.0.0.1:8000/api/health

GET /api/config/services

获取已启用的服务列表

🎵 Suno 音乐生成 API

GET /api/suno/health

Suno 服务健康检查
curl http://127.0.0.1:8000/api/suno/health

GET /api/suno/credits

查询剩余积分
curl http://127.0.0.1:8000/api/suno/credits

POST /api/suno/generate 高优先级

生成音乐
参数:
  • prompt (必需): 提示词或歌词
  • model: 模型版本 (V3_5, V4, V4_5, V5)，默认 V5
  • customMode: 是否自定义模式，默认 false
  • style: 音乐风格 (customMode=true 时需要)
  • title: 歌曲标题 (customMode=true 时需要)
  • instrumental: 是否纯音乐
curl -X POST http://127.0.0.1:8000/api/suno/generate \ -H "Content-Type: application/json" \ -d '{"prompt": "轻快的流行歌曲", "model": "V5"}'

POST /api/suno/cover 高优先级

AI 翻唱 - 改变风格、音色或多语言翻唱
参数: uploadUrl, style, title, prompt (新歌词)
curl -X POST http://127.0.0.1:8000/api/suno/cover \ -H "Content-Type: application/json" \ -d '{"uploadUrl": "https://...", "style": "rock"}'

POST /api/suno/upload/stream

上传音频文件（用于翻唱）
curl -X POST http://127.0.0.1:8000/api/suno/upload/stream \ -F "file=@music.mp3" \ -F "upload_path=music"

POST /api/suno/extend

延长现有音乐

POST /api/suno/separate-vocals

人声/伴奏分离

GET /api/suno/task/{task_id}

查询任务状态
curl http://127.0.0.1:8000/api/suno/task/xxx-task-id

🤖 Doubao AI API

GET /api/doubao/health

Doubao 服务健康检查
curl http://127.0.0.1:8000/api/doubao/health

POST /api/doubao/lyrics

使用 DeepSeek-V3 生成歌词
参数: prompt (歌词创作提示), system_prompt, temperature
curl -X POST http://127.0.0.1:8000/api/doubao/lyrics \ -H "Content-Type: application/json" \ -d '{"prompt": "写一首关于春天的歌"}'

POST /api/doubao/image/generate

生成图像（专辑封面等）
参数: prompt (图像描述), size (默认 2K), watermark
curl -X POST http://127.0.0.1:8000/api/doubao/image/generate \ -H "Content-Type: application/json" \ -d '{"prompt": "专辑封面，星空主题"}'

POST /api/doubao/image/understand

图像理解 - 分析图片内容、氛围、情绪
参数: image_url, question

POST /api/doubao/image/to-song 特色功能

图片成歌 - 分析图片并提取音乐创作元素（场景、情绪、风格、乐器等）
参数: image_url
curl -X POST http://127.0.0.1:8000/api/doubao/image/to-song \ -H "Content-Type: application/json" \ -d '{"image_url": "https://..."}'

POST /api/doubao/video/generate

生成视频（支持文生视频和图生视频）
参数: prompt, image_url (可选), ratio (16:9), duration (秒)

POST /api/doubao/video/music-video

创建音乐 MV - 根据歌词和风格生成匹配的视频
参数: lyrics, style (默认"流行"), image_url (封面)
curl -X POST http://127.0.0.1:8000/api/doubao/video/music-video \ -H "Content-Type: application/json" \ -d '{"lyrics": "歌词内容...", "style": "摇滚"}'

🎼 音乐创作工作流

POST /api/music-workflow/create 完整流程

完整的 AI 音乐创作工作流：
1. 使用 DeepSeek 生成歌词
2. 自动调用 Suno 生成音乐
参数: template (模板), user_input (用户输入), auto_generate_music

GET /api/music-workflow/templates

获取所有可用的创作模板
curl http://127.0.0.1:8000/api/music-workflow/templates

📦 使用 Postman 测试

1. 打开 Postman 或 Insomnia
2. 导入 OpenAPI 规范：下载 openapi.json
3. 或者直接使用上面的 curl 命令测试
4. 所有 POST 请求记得添加头部：Content-Type: application/json

🚀 快速开始

1. 检查服务状态

curl http://127.0.0.1:8000/api/health

2. 查询 Suno 积分

curl http://127.0.0.1:8000/api/suno/credits

3. 生成一首音乐

curl -X POST http://127.0.0.1:8000/api/suno/generate \ -H "Content-Type: application/json" \ -d '{ "prompt": "a catchy pop song about summer", "model": "V5" }'

4. 使用 Doubao 生成歌词

curl -X POST http://127.0.0.1:8000/api/doubao/lyrics \ -H "Content-Type: application/json" \ -d '{ "prompt": "写一首关于追梦的励志歌曲" }'
