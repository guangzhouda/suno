# 快速入门 - 5分钟上手豆包音乐创作

## ⚡ 30秒安装

```bash
# 1. 安装依赖
pip install volcengine-python-sdk[ark]

# 2. 设置API Key
set ARK_API_KEY=your_api_key      # Windows
export ARK_API_KEY=your_api_key   # Linux/Mac
```

## 🎵 第一个作品（2分钟）

### 复制粘贴运行

创建文件 `my_first_song.py`：

```python
from modules.clients import doubao_text, doubao_image, doubao_downloader
import os

# 创建文件夹
os.makedirs("outputs/my_first_song", exist_ok=True)

# 1. 生成歌词
print("创作歌词...")
lyrics = doubao_text.generate_lyrics(
    prompt="夏天的海边",
    style="清新流行"
)

# 2. 保存歌词
with open("outputs/my_first_song/lyrics.txt", 'w', encoding='utf-8') as f:
    f.write(lyrics)
print("✓ 歌词已保存")

# 3. 生成封面
print("设计封面...")
cover = doubao_image.generate_album_cover(
    title="夏日海边",
    style="清新流行",
    elements="海浪、阳光"
)

# 4. 下载封面
print("下载封面...")
cover_file = doubao_downloader.download_image(
    url=cover['url'],
    save_dir="outputs/my_first_song",
    filename="cover.jpg"
)

print("\n✓ 完成！")
print("文件保存在: outputs/my_first_song/")
```

运行：
```bash
python my_first_song.py
```

## 🔥 常用代码片段

### 1. 生成歌词

```python
from modules.clients import doubao_text

lyrics = doubao_text.generate_lyrics(
    prompt="你的主题",
    style="流行",      # 流行/摇滚/民谣/说唱/古风
    mood="欢快"        # 欢快/忧郁/激情/宁静
)

print(lyrics)
```

### 2. 生成封面并下载

```python
from modules.clients import doubao_image, doubao_downloader

# 生成
cover = doubao_image.generate_album_cover(
    title="歌曲名",
    style="流行",
    elements="元素描述"
)

# 下载
file_path = doubao_downloader.download_image(
    url=cover['url'],
    save_dir="outputs",
    filename="cover.jpg"
)
```

### 3. 图片成歌

```python
from modules.clients import doubao_vision, doubao_text

# 分析图片
elements = doubao_vision.image_to_music_prompt(
    image_url="https://example.com/photo.jpg"
)

# 根据分析生成歌词
lyrics = doubao_text.generate_lyrics(
    prompt=elements['scene'],
    style=elements['style'],
    mood=elements['emotion']
)
```

### 4. 生成MV

```python
from modules.clients import doubao_video

mv = doubao_video.generate_mv(
    lyrics="你的歌词",
    style="流行",
    scene="海边",
    ratio="16:9"
)

print(f"任务ID: {mv['task_id']}")
# 访问 https://console.volcengine.com/ 查看进度
```

### 5. 完整流程

```python
from modules.clients import *

# 1. 生成歌词
lyrics = doubao_text.generate_lyrics(prompt="主题")

# 2. 生成封面
cover = doubao_image.generate_album_cover(title="歌名")

# 3. 下载封面
file = doubao_downloader.download_image(
    url=cover['url'],
    save_dir="outputs"
)

# 4. 生成MV
mv = doubao_video.generate_mv(
    lyrics=lyrics,
    cover_image_url=cover['url']
)

print("完成！")
```

## 💡 3个实用技巧

```python

# 创建项目文件夹
project_dir = "outputs/my_project"
os.makedirs(project_dir, exist_ok=True)

with open(f"{project_dir}/lyrics.txt", 'w', encoding='utf-8') as f:
```

```python
# 如果对初稿不满意
```

## ❓ 遇到问题？

### API Key错误

```bash
# 检查环境变量
echo %ARK_API_KEY%  # Windows
echo $ARK_API_KEY   # Linux/Mac

# 重新设置
set ARK_API_KEY=your_key
```

### 导入错误

确保在项目根目录运行：
```bash
# 当前目录应该是
E:\Projects\PythonProject\

# 运行
python examples/your_script.py
```

### 图片URL打不开

URL有效期14-30天，建议：
```python
# 生成后立即下载
result = doubao_image.generate_album_cover(...)
file = doubao_downloader.download_image(url=result['url'], ...)
```
