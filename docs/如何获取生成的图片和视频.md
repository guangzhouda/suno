# 如何获取生成的图片和视频

## 📸 图片获取方式

### 方式1：使用返回的URL（临时访问）

生成图片后，API会返回一个URL：

```python
from modules.clients import doubao_image

# 生成图片
result = doubao_image.generate_album_cover(
    title="夏日回忆",
    style="清新流行",
    size="1K"
)

# 获取URL
print(f"图片URL: {result['url']}")
# 输出示例: https://xxxx.volces.com/images/xxx.jpg
```

**重要提示：**
- ⏰ URL有效期：通常为 **14-30天**
- ⚠️ 过期后无法访问
- 💡 建议立即下载到本地

### 方式2：下载到本地（推荐）

使用下载工具直接保存到本地：

```python
from modules.clients import doubao_image, doubao_downloader

# 1. 生成图片
result = doubao_image.generate_album_cover(...)

# 2. 立即下载到本地
file_path = doubao_downloader.download_image(
    url=result['url'],
    save_dir="outputs/my_covers",  # 保存目录
    filename="album_cover.jpg"      # 文件名
)

print(f"图片已保存: {file_path}")
# 输出: 图片已保存: outputs/my_covers/album_cover.jpg
```

### 方式3：批量下载

如果生成了多张图片：

```python
from modules.clients import doubao_downloader

# 图片URL列表
image_urls = [
    "https://example.com/img1.jpg",
    "https://example.com/img2.jpg",
    "https://example.com/img3.jpg"
]

# 批量下载
file_paths = doubao_downloader.batch_download_images(
    urls=image_urls,
    save_dir="outputs/batch_covers",
    prefix="cover"  # 文件名前缀：cover_1.jpg, cover_2.jpg...
)
```

## 🎬 视频获取方式

### 视频生成流程说明

**重要：** 视频生成是**异步任务**，不是立即完成的！

```
提交任务 → 等待处理（几分钟到十几分钟）→ 完成 → 下载
```

### 步骤1：提交视频生成任务

```python
from modules.clients import doubao_video

# 提交任务
result = doubao_video.generate_mv(
    lyrics="风吹过海面，带走了思念",
    style="抒情流行",
    scene="海边日落",
    ratio="16:9"
)

# 记录任务ID（重要！）
task_id = result['task_id']
print(f"任务ID: {task_id}")
print(f"状态: {result['status']}")  # 输出: submitted
```

**此时视频还没有生成！只是提交了任务。**

### 步骤2：查询任务状态（方式选择）

#### 方式A：通过豆包官方控制台（推荐）

1. 访问：https://console.volcengine.com/
2. 登录你的豆包账号
3. 进入"内容生成"或"视频生成"页面
4. 查找你的任务ID
5. 等待任务完成后，在控制台下载视频

#### 方式B：使用API查询（如果支持）

如果豆包提供了任务查询API：

```python
from modules.clients import doubao_downloader

# 查询任务状态
status = doubao_downloader.query_video_task(task_id)

print(f"状态: {status['status']}")  # processing/completed/failed
print(f"进度: {status['progress']}%")

# 如果完成了
if status['status'] == 'completed':
    video_url = status['video_url']
    print(f"视频URL: {video_url}")
```

**注意：** 目前豆包可能不提供公开的查询API，需要使用控制台。

#### 方式C：自动等待并下载

```python
from modules.clients import doubao_downloader

# 提交任务后，自动等待完成并下载
video_path = doubao_downloader.wait_for_video(
    task_id=task_id,
    save_dir="outputs/videos",
    filename="my_mv.mp4",
    max_wait_time=600  # 最多等待10分钟
)

if video_path:
    print(f"视频已保存: {video_path}")
else:
    print("视频生成超时或失败")
```

### 步骤3：下载视频

如果你已经有视频URL（从控制台或API获取）：

```python
from modules.clients import doubao_downloader

# 下载视频
video_path = doubao_downloader.download_video(
    url="https://example.com/your_video.mp4",
    save_dir="outputs/mvs",
    filename="summer_mv.mp4",
    show_progress=True  # 显示下载进度
)

print(f"视频已保存: {video_path}")
```

## 📁 文件保存位置

默认保存目录结构：

```
项目根目录/
├── outputs/
│   ├── images/          # 图片
│   ├── album_covers/    # 专辑封面
│   ├── videos/          # 视频
│   ├── mvs/             # 音乐MV
│   └── complete_works/  # 完整作品
```

你可以自定义保存位置：

```python
# 自定义保存目录
file_path = doubao_downloader.download_image(
    url=image_url,
    save_dir="D:/my_music_project/covers",  # Windows绝对路径
    filename="cover.jpg"
)
```

## ❓ 常见问题

### Q1: 图片URL打不开了怎么办？

**原因：** URL可能已过期（通常14-30天）

**解决：**
- 重新生成图片
- 或者在生成后立即下载保存

### Q2: 视频生成要等多久？

**时间：** 通常 **5-15分钟**，取决于：
- 视频时长
- 视频比例
- 服务器负载

**建议：**
- 提交任务后记录task_id
- 去做其他事情
- 过几分钟后再查询

### Q3: 如何查看下载进度？

图片下载通常很快（几秒），视频下载会显示进度：

```python
# 下载时会显示进度条
下载进度: 45.2% (4521234/10000000 字节)
```

### Q4: 下载失败怎么办？

**可能原因：**
1. 网络连接问题 - 检查网络
2. URL已过期 - 重新生成
3. 磁盘空间不足 - 清理空间

**解决方法：**
```python
try:
    file_path = doubao_downloader.download_image(url=url, ...)
    print(f"成功: {file_path}")
except Exception as e:
    print(f"失败: {e}")
    # 重试或检查错误
```

### Q5: 可以下载之前生成的图片吗？

可以！只要你还有URL且URL未过期：

```python
# 之前生成时保存的URL
old_url = "https://xxxx.volces.com/images/old_cover.jpg"

# 直接下载
file_path = doubao_downloader.download_image(
    url=old_url,
    save_dir="outputs/old_images"
)
```

## 💡 最佳实践

1. **立即下载**
   - 生成后立即下载到本地
   - 不要依赖临时URL

2. **组织文件**
   - 使用有意义的文件名
   - 按项目/日期分类保存

3. **备份重要文件**
   - 定期备份生成的作品
   - 使用云存储或外部硬盘

4. **记录任务ID**
   - 视频任务ID要记录下来
   - 方便后续查询

5. **批量处理**
   - 一次生成多个资源
   - 使用批量下载功能
