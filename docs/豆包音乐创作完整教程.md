## 模块介绍

### 五个核心模块

| 模块 | 文件 | 主要功能 | 使用场景 |
|------|------|---------|---------|
| 📝 **文本模块** | `doubao_text.py` | 生成歌词、对话 | 歌词创作、优化 |
| 🎨 **图像模块** | `doubao_image.py` | 生成图片 | 专辑封面、海报 |
| 👁️ **视觉模块** | `doubao_vision.py` | 分析图片 | 图片成歌、提取元素 |
| 🎬 **视频模块** | `doubao_video.py` | 生成视频 | 音乐MV、短视频 |
| 💾 **下载模块** | `doubao_downloader.py` | 下载资源 | 保存图片和视频 |

### 工作流程图

```
创意想法
  ↓
文本模块 → 生成歌词
  ↓
图像模块 → 生成封面
  ↓
下载模块 → 保存到本地
  ↓
视频模块 → 生成MV
  ↓
完整作品
```

或者：

```
一张图片
  ↓
视觉模块 → 分析图片（提取场景、情绪、风格）
  ↓
文本模块 → 根据分析生成歌词
  ↓
图像模块 → 生成配套封面
  ↓
下载模块 → 保存所有资源
  ↓
视频模块 → 生成MV
  ↓
完整作品
```

## 基础使用

### 第一课：生成歌词

#### 最简单的例子

```python
from modules.clients import doubao_text

# 生成歌词
lyrics = doubao_text.generate_lyrics(
    prompt="夏天的海边"
)

print(lyrics)
```

**输出示例：**
```
[Verse 1]
阳光洒在沙滩上
海浪拍打着岸边
...
```

#### 自定义风格和情绪

```python
lyrics = doubao_text.generate_lyrics(
    prompt="夏天的海边",
    style="民谣",           # 音乐风格
    mood="轻松愉快",         # 情绪氛围
    language="中文",        # 语言
    temperature=0.8        # 创造性（0-1，越高越有创意）
)
```

#### 可用的风格

| 风格 | 特点 | 适合场景 |
|------|------|---------|
| 流行 | 朗朗上口，易传唱 | 大众音乐 |
| 摇滚 | 激情澎湃，力量感强 | 表达态度 |
| 民谣 | 质朴真诚，故事性强 | 叙事歌曲 |
| 说唱 | 节奏感强，押韵讲究 | 快节奏表达 |
| 古风 | 典雅诗意，意境悠远 | 传统主题 |
| 电子 | 未来感，科技氛围 | 现代音乐 |

#### 优化歌词

```python
# 如果对初稿不满意，可以优化
original = doubao_text.generate_lyrics(prompt="友情")

# 优化
refined = doubao_text.refine_lyrics(
    original_lyrics=original,
    refinement_request="让副歌更有感染力，增加细节描写"
)
```

### 技巧4: 批量处理

```python

    {"title": "春", "theme": "春天", "mood": "欢快"},

        prompt=theme_config['theme'],

    )

        title=theme_config['title'],

    # 保存歌词
    with open(f"outputs/{theme_config['title']}/lyrics.txt", 'w', encoding='utf-8') as f:
        f.write(lyrics)

    print(f"✓ 《{theme_config['title']}》完成")
```

### 案例3: 专业制作流程

**目标：** 多版本迭代，选择最佳方案

```python
from modules.clients import *
import os

# 创建项目文件夹
project_dir = "outputs/professional_song"
os.makedirs(project_dir, exist_ok=True)
os.makedirs(f"{project_dir}/lyrics_versions", exist_ok=True)
os.makedirs(f"{project_dir}/cover_options", exist_ok=True)

# 定义创作概念
concept = {
    "title": "追梦人",
    "theme": "追逐梦想",
    "style": "励志流行",
    "mood": "激情昂扬"
}

print("=== 专业音乐制作流程 ===\n")
print(f"歌曲: {concept['title']}")
print(f"主题: {concept['theme']}\n")

# 阶段1: 创作多个歌词版本
print("阶段1: 创作歌词版本...")

versions = []
for i in range(3):
    print(f"  版本 {i+1}...")
    lyrics = doubao_text.generate_lyrics(
        prompt=concept['theme'],
        style=concept['style'],
        mood=concept['mood'],
        temperature=0.7 + i*0.1  # 不同的创造性
    )

    # 保存版本
    version_file = f"{project_dir}/lyrics_versions/v{i+1}.txt"
    with open(version_file, 'w', encoding='utf-8') as f:
        f.write(lyrics)

    versions.append(lyrics)
    print(f"    ✓ 已保存: {version_file}")

# 选择最佳版本（这里选第2版，实际应该人工评估）
best_lyrics = versions[1]
with open(f"{project_dir}/lyrics_final.txt", 'w', encoding='utf-8') as f:
    f.write(best_lyrics)

print("\n阶段2: 设计封面方案...")

cover_themes = ["科技感", "手绘风格", "简约现代"]
cover_urls = []

for theme in cover_themes:
    print(f"  方案: {theme}...")
    cover = doubao_image.generate_album_cover(
        title=concept['title'],
        style=f"{concept['style']} - {theme}",
        mood=concept['mood']
    )

    # 下载
    cover_file = doubao_downloader.download_image(
        url=cover['url'],
        save_dir=f"{project_dir}/cover_options",
        filename=f"{theme}.jpg"
    )

    cover_urls.append(cover['url'])
    print(f"    ✓ {cover_file}")

# 选择最佳封面（选第一个）
final_cover_url = cover_urls[0]

print("\n阶段3: 生成MV...")
mv = doubao_video.generate_mv(
    lyrics=best_lyrics,
    style=concept['style'],
    mood=concept['mood'],
    cover_image_url=final_cover_url
)

print(f"  ✓ MV任务ID: {mv['task_id']}")

print("\n=== 制作完成 ===")
print(f"项目文件夹: {project_dir}")
print(f"  - 歌词版本: 3个")
print(f"  - 封面方案: {len(cover_themes)}个")
print(f"  - MV任务: {mv['task_id']}")
```

## 常见问题

### Q1: 如何选择合适的温度参数？

**温度范围：** 0.0 - 1.0

- **0.3-0.5**: 稳定保守，适合优化、改进
- **0.6-0.8**: 平衡创造性，适合大部分场景（推荐）
- **0.8-1.0**: 高创造性，适合实验、头脑风暴

### Q2: 图片URL多久过期？

**答：** 通常 14-30天

**建议：** 生成后立即下载到本地

### Q3: 视频生成要多久？

**答：** 通常 5-15分钟

**建议：**
- 提交任务后记录task_id
- 过几分钟后查询状态
- 或者访问豆包控制台查看

### Q4: 如何提高生成质量？

**歌词：**
- 提供详细的prompt
- 指定明确的风格和情绪
- 使用优化功能迭代改进

**封面：**
- 描述具体的视觉元素
- 指定色彩方案
- 尝试多个方案选最佳

**视频：**
- 使用详细的镜头描述
- 提供高质量的首帧图片
- 描述清楚动作和场景变化

### Q5: 如何批量创作？

**参考代码：**
```python
themes = ["春天", "夏天", "秋天", "冬天"]

for theme in themes:
    # 创作歌词
    lyrics = doubao_text.generate_lyrics(prompt=theme)

    # 生成封面
    cover = doubao_image.generate_album_cover(title=theme)

    # 下载
    doubao_downloader.download_image(
        url=cover['url'],
        save_dir=f"outputs/{theme}"
    )
```

### Q6: 出错了怎么办？

**常见错误：**

1. **API Key错误**
   - 检查环境变量是否设置
   - 确认key是否正确

2. **网络错误**
   - 检查网络连接
   - 重试请求

3. **下载失败**
   - URL可能已过期
   - 重新生成

4. **视频任务查询失败**
   - 访问豆包官方控制台
   - 使用task_id查找
