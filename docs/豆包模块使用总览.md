# 豆包AI音乐创作模块 - 使用总览

> 五个模块，一站式音乐创作解决方案

## 📦 模块清单

| 模块文件 | 功能 | 主要函数 |
|---------|------|---------|
| `doubao_text.py` | 歌词生成 | `generate_lyrics()`, `refine_lyrics()`, `chat()` |
| `doubao_image.py` | 图像生成 | `generate_album_cover()`, `generate_image()` |
| `doubao_vision.py` | 图像理解 | `image_to_music_prompt()`, `understand_image()` |
| `doubao_video.py` | 视频生成 | `generate_mv()`, `text_to_video()` |
| `doubao_downloader.py` | 资源下载 | `download_image()`, `download_video()` |

## ⚡ 快速开始

### 1. 安装（30秒）

```bash
pip install volcengine-python-sdk[ark]
set ARK_API_KEY=your_key  # Windows
```

### 2. 第一个作品（2分钟）

```python
from modules.clients import doubao_text, doubao_image, doubao_downloader

# 生成歌词
lyrics = doubao_text.generate_lyrics(prompt="夏天的海边")

# 生成封面
cover = doubao_image.generate_album_cover(title="夏日")

# 下载封面
file = doubao_downloader.download_image(
    url=cover['url'],
    save_dir="outputs"
)

print("完成！")
```

### 3. 运行示例

```bash
python examples/music_creator_complete.py
```

## 🎯 使用场景

### 场景1: 快速创作
**需求**: 有一个主题，想快速生成歌词和封面

```python
from modules.clients import doubao_text, doubao_image, doubao_downloader

# 生成歌词
lyrics = doubao_text.generate_lyrics(
    prompt="春天的花园",
    style="民谣"
)

# 生成封面
cover = doubao_image.generate_album_cover(
    title="春之歌",
    style="民谣"
)

# 下载
doubao_downloader.download_image(
    url=cover['url'],
    save_dir="outputs/spring_song"
)
```

**推荐文档**: [快速入门](快速入门-5分钟上手.md)

### 场景2: 图片成歌
**需求**: 从一张图片创作完整音乐作品

```python
from modules.clients import doubao_vision, doubao_text, doubao_image, doubao_video

# 分析图片
elements = doubao_vision.image_to_music_prompt(image_url)

# 生成歌词
lyrics = doubao_text.generate_lyrics(
    prompt=elements['scene'],
    style=elements['style']
)

# 生成封面
cover = doubao_image.generate_album_cover(
    title="AI音乐",
    style=elements['style']
)

# 生成MV
mv = doubao_video.generate_mv(
    lyrics=lyrics,
    cover_image_url=cover['url']
)
```

### 场景4: 批量创作

## 🛠️ 工具函数速查

### 文本模块 (doubao_text.py)

```python
# 生成歌词
lyrics = doubao_text.generate_lyrics(
    prompt="主题",
    style="流行",      # 流行/摇滚/民谣/说唱/古风/电子
    mood="欢快",       # 欢快/忧郁/激情/宁静/温暖
    language="中文",
    temperature=0.8   # 0-1，越高越有创意
)

# 优化歌词
refined = doubao_text.refine_lyrics(
    original_lyrics=lyrics,
    refinement_request="让副歌更有力量感",
    temperature=0.5
)

# 自定义对话
response = doubao_text.chat(
    messages=[
        {"role": "system", "content": "你是专业作词人"},
        {"role": "user", "content": "给我一些写歌建议"}
    ]
)
```

### 图像模块 (doubao_image.py)

```python
# 生成专辑封面
cover = doubao_image.generate_album_cover(
    title="歌名",
    artist="歌手",
    style="流行",
    mood="欢快",
    color_scheme="暖色调",  # 暖色调/冷色调/黑白/莫兰迪...
    elements="海边、夕阳",
    size="1K"  # 1K或2K
)

# 根据歌词生成封面
cover = doubao_image.generate_cover_from_lyrics(
    lyrics=lyrics,
    style="民谣"
)

# 自定义图像
image = doubao_image.generate_image(
    prompt="详细描述",
    size="2K",
    watermark=False
)

# 生成海报
poster = doubao_image.generate_poster(
    event_name="音乐节",
    date="2025-07-15",
    venue="海滨公园"
)
```

### 视觉模块 (doubao_vision.py)

```python
# 图片理解
description = doubao_vision.understand_image(
    image_url="https://...",
    question="描述这张图片"
)

# 图片成歌（提取音乐元素）
elements = doubao_vision.image_to_music_prompt(image_url)
# 返回: scene, emotion, style, instruments, tempo...

# 生成歌词创作提示
prompt = doubao_vision.image_to_lyrics_prompt(image_url)

# 识别物体
objects = doubao_vision.extract_objects(image_url)

# 分析色彩
palette = doubao_vision.get_color_palette(image_url)
```

### 视频模块 (doubao_video.py)

```python
# 生成MV（最简单）
mv = doubao_video.generate_mv(
    lyrics="歌词",
    style="流行",
    scene="海边",
    mood="温暖",
    cover_image_url="https://...",  # 可选
    ratio="16:9",  # 16:9/9:16/1:1/adaptive
    duration=5
)

# 文生视频
video = doubao_video.text_to_video(
    prompt="镜头描述",
    ratio="16:9",
    duration=5
)

# 图生视频
video = doubao_video.image_to_video(
    image_url="https://...",
    prompt="动作描述",
    duration=5
)

# 歌词视频
lyric_video = doubao_video.generate_lyric_video(
    lyrics_line="歌词内容",
    style="简约现代",
    background="渐变色"
)

# 概念视频
concept = doubao_video.generate_concept_video(
    concept="时间与记忆",
    style="超现实主义"
)
```

### 下载模块 (doubao_downloader.py)

```python
# 下载图片
file_path = doubao_downloader.download_image(
    url="https://...",
    save_dir="outputs/images",
    filename="cover.jpg",
    overwrite=False
)

# 批量下载
files = doubao_downloader.batch_download_images(
    urls=[url1, url2, url3],
    save_dir="outputs/batch",
    prefix="img"
)

# 下载视频
video_path = doubao_downloader.download_video(
    url="https://...",
    save_dir="outputs/videos",
    show_progress=True
)

# 查询视频任务
status = doubao_downloader.query_video_task(task_id)

# 等待视频完成并下载
video = doubao_downloader.wait_for_video(
    task_id=task_id,
    save_dir="outputs",
    max_wait_time=600
)

# 获取文件信息
info = doubao_downloader.get_file_info(file_path)
```

## 💡 使用技巧

1. **立即下载**: 生成图片后立即下载，URL有效期14-30天
2. **记录任务ID**: 视频生成后记录task_id
3. **温度参数**: 创作用0.8，优化用0.5
4. **批量处理**: 使用循环批量创作
5. **保存项目**: 每个作品创建独立文件夹
